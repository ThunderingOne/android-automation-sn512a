=== MTKClient Bootloader Unlock ===
MTKClient is an open-source tool for MediaTek devices
It can unlock bootloader without OEM approval using BROM exploit

Requirements:
1. Download mtkclient from: https://github.com/bkerler/mtkclient
2. Install Python 3.8+ and dependencies
3. Install USB drivers for MediaTek

Steps:
1. Boot device to BROM mode:
   - Power off device
   - Hold Volume Up + Volume Down + Power
   - Connect via USB
   - Device should enter BROM mode

2. Run mtkclient commands:
   - First wipe metadata: python mtk.py e metadata,userdata,md_udc
   - Then unlock bootloader: python mtk.py da seccfg unlock

WARNING: This will erase all data on the device!
Backup important data before proceeding!

AT&T Unlock Requirements:
1. Device must be paid in full (no balance)
2. Device must be active on AT&T network for:
   - Postpaid: 60+ days
   - Prepaid: 6+ months
3. Device not reported lost/stolen
4. Account in good standing

Unlock Method:
1. Visit: https://att.com/deviceunlock
2. Enter IMEI and device details
3. Wait for approval (24-48 hours)
4. Receive 16-digit unlock code
5. Insert non-AT&T SIM and enter code
